Verify it yourself

Check any record without trusting this site

ots verify preregistration.sha256.ots
sha256sum preregistration.frozen.json

The first command asks Bitcoin when the file existed. The second recomputes the hash from the sealed document. If the hash matches what is published here and the timestamp predates the result, the claim was fixed before the answer was known — and no part of that depends on believing anything I say.

How the links are computed

chain[0] = sha256("sweep-registry-genesis")
chain[i] = sha256(chain[i-1] + sweep_id + preregistration_sha256)

Each link folds in the one before it. Deleting an inconvenient record is the obvious temptation for a registry of failures, and this is what makes it visible: every later link would stop matching.
